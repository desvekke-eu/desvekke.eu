Personal Google Backup

This is a private, non-commercial project for creating independent local backups of personal Google account data.

Purpose

The goal is to preserve email messages and files in standard, portable formats that remain accessible without relying on Google or a particular backup application.

How it works

The project uses open-source tools to retrieve Gmail messages and Google Drive files with authorization from the account owner. Backup data is stored on privately managed local storage.

Access and security

The application is intended exclusively for personal use by the owner of the Google account. It uses Google's OAuth authorization mechanism and requests read-only access to the data required for backups.
