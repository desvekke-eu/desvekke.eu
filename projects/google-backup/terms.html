1. About This Project

Personal Google Backup is a private, non-commercial project designed to create independent local backups of the project owner's Google account data.

2. Intended Use

The application is intended exclusively for personal use by the project owner. It is not offered as a public backup service, and no accounts are provided to third parties.

3. Google Account Authorization

Access to Google account data requires authorization from the account owner through Google's OAuth authorization process.

The application is intended to use read-only permissions to retrieve Gmail messages and Google Drive files for local backup purposes.

4. Data Ownership

All retrieved account data remains the property of its respective owner or rights holders. The application does not claim ownership of backed-up information.

5. Data Storage

Retrieved data is stored on privately managed local storage systems. It is not made publicly available through this website.

This project is provided for personal use without guarantees of uninterrupted operation, complete data retrieval, or successful recovery. Backups should be periodically verified.

Functionality may be affected by changes to Google's APIs, authentication requirements, or service availability.
